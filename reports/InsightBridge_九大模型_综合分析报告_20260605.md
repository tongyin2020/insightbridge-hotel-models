### 🔴 异常一：MARE 4★ 和 SelfACQ 4★ 定价过激

**问题**：MARE 4★ 均价1,318（+37.7%）、SelfACQ 4★ 均价1,554（+62.4%），均超过 DSEC 4★市场均价957 MOP 过多。

- MARE 4★ 弹性系数设置过低（价格敏感性低估），弹性引擎搜索上限偏高
- SelfACQ 4★ 直销偏差系数（`direct_bias`）在高竞对场景下叠加效应导致报价虚高
- 当前弹性系数 4★ COTAI ≈ 0.60，实际澳门4★市场更具价格敏感性

**建议调整**：
```python
# elasticity_engine.py
(4, "COT"):  0.72  # 从 0.60 调高（路氹4★ 竞争激烈）
(4, "TAIPA"): 0.75  # 从 0.63 调高
# SelfACQ 直销溢价上限：从 45% 降至 30%
```

### 🔴 异常二：MARE 5★ 最高价 5,200 MOP

### 🔴 异常三（严重）：MARE_23_STAR 正常率仅 9.2%

**这是全系统最大问题**，共 35,670 条记录中仅 3,276 条（9.2%）完全正常。

**异常分解：**

| 异常类型 | 数量 | 占比 | 性质 |
|---------|------|------|------|
| `price_floor_ceiling` GUARDRAIL | 18,060 | 50.6% | 🔴 模型输出超出价格护栏 |
| EXCEPTION: PermissionError | 7,540 | 21.1% | 🔴 文件读写权限错误（历史遗留，H79-H130期间） |
| `gm_approval` GUARDRAIL | ~8,000 | 22.4% | ⚠️ GM审批阈值触发 |
| `competitor_deviation` | ~2,900 | 8.1% | ⚠️ 竞对偏差（6月淡季正常） |

**根因分析**：

**`price_floor_ceiling`（50.6%）**：MARE_23_STAR 均价820 MOP，price_floor_ceiling 规则的价格上限设置为 1,000 MOP（`PolicyEngine` 中3★上限），但该模型在旺季场景输出高达 1,116 MOP，频繁触发上限截断。同时在淡季场景 750 MOP 触发下限。价格护栏范围（floor=750, ceiling=1,000）过窄。

**`PermissionError`（21.1%）**：发生在 H79-H130 期间（约2026-05-13前），`model_weights.json` 文件权限问题（之前已修复，后续不再出现）。历史数据无法更改，但已确认修复。

**建议调整**：
```python
# 系统二 _hotel_settings()
# MARE_23_STAR 适用的 3★ 护栏扩大
3: SimpleNamespace(floor_price=400, ceiling_price=1200)  # ceiling: 1000→1200
```

### ⚠️ 异常六：SELFACQ_ALL 1% LOGIC异常

**问题**：195条 "直销净收益低于OTA净收益——自主获客模型失效"，均价1,375 MOP。

**根因**：这是 DEMAND_COLLAPSE / PRICE_WAR 场景下直销价格仍被维持在高位，而 OTA 大幅降价后直销净收益反而低于OTA。属场景设计正常现象，**自主获客模型在价格战场景应更激进降价**。

**建议调整**：
```python
# PRICE_WAR 场景下 SelfACQ 的 direct_bias 应降低
if scenario == "PRICE_WAR":
    direct_bias = max(0.05, direct_bias * 0.6)  # 更激进跟随市场
```
