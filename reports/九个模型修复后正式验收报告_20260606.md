## 本轮修复项

### 1. System 1 Director 忠诚度崩溃修复

- 文件：`system2_claude_simulation/run_simulation.py`
- 问题：场景会生成 `vip` / `diamond`，但 CRM 折扣与 upsell 映射只接受 `platinum/gold/silver/bronze/none`
- 表现：`Director` 在 System 1 复跑中曾出现 `228/836` 次失败，典型报错为 `{'error': "'vip'"}` 和 `{'error': "'diamond'"}` 
- 修复：先将 `vip` / `diamond` 归一到 `platinum` 逻辑，再进入折扣、护栏与 upsell 计算

### 2. System 2 落库结构修复

- 文件：`system2_claude_simulation/run_simulation.py`
- 问题：函数返回值已经带 V6 统一字段，但写入 `hourly_runs.output_json` 时又被裁回旧结构
- 影响：数据库中的 `MARE_ALL / DIRECTOR_CRM_ALL / SELFACQ_ALL` 记录看起来像“还没完成 V6 接入”
- 修复：保存完整 `result`，只额外补充 `scenario` / `scenario_category` / `competitor_mult` 等元信息

### 3. 自动启动 `.env` 加载修复

- 文件：`auto_run_9models.sh`
- 问题：脚本直接 `source .env`，当值中带空格时会被 shell 误当命令执行
- 典型例子：
  - `HOTEL_NAME=The Venetian Macao`
  - `MODEL_BASE_PATH=/Users/tongyin/Desktop/Hotel Model Rvisions`
- 修复：改为通过 `python-dotenv` 安全解析并导出环境变量
